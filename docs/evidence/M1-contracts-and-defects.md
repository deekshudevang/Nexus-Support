## 1. Critical Defects Addressed

### Defect E3: Nullable GPS Constraint Violation in Pydantic Schema & DB
- **Cause:** `cloud/backend/main.py` enforced `latitude REAL NOT NULL` and Pydantic `latitude: float = Field(...)`, rejecting valid emergency SOS packets generated by victims indoors, underground, or in dense canopy without GPS locks.
- **Remedy:**
  - Updated `SosPacket` model with `latitude: Optional[float] = None`, `longitude: Optional[float] = None`, and `gpsFixAvailable: Optional[bool] = None`.
  - Updated `init_db()` in `cloud/backend/main.py` with nullable coordinates and automatic schema column migration for `gpsFixAvailable`.
  - Added route alias `@app.post("/api/v1/sync/sos")`.
  - Updated `sync_sos` response to emit per-event receipts.
- **Verification:**
  - Added `test_sync_sos_nullable_gps_and_receipts` in `test_backend.py`.
  - Backend pytest suite: **29 PASSED / 0 FAILED**.

### Defect E1: GatewaySyncWorker Hardcoding & Per-Event Reconciliation
- **Cause:** `GatewaySyncWorker.kt` had a hardcoded emulator endpoint (`10.0.2.2:8000`), omitted the gateway authentication header (`X-Gateway-Key`), and did not reconcile per-event receipts back into the local Room database.
- **Remedy:**
  - Added configurable URL and key support via WorkManager `inputData` (`KEY_GATEWAY_URL`, `KEY_GATEWAY_KEY`).
  - Added `X-Gateway-Key` and `Authorization: Bearer <key>` headers.
  - Implemented per-event receipt parsing and local Room database update via `sosDao.updateStatus(uuid, "ACKNOWLEDGED")`.
  - Added network constraints and exponential backoff helper `buildWorkRequest`.
- **Verification:**
  - Added unit test suite `GatewaySyncWorkerTest.kt` verifying no-op on empty database, no-op when all packets are acknowledged, and retry on network failure.

### Defect E4: MeshtasticTransport Premature Success & Non-Deterministic Node IDs
- **Cause:** `MeshtasticTransport.kt` used `String.hashCode()` for 32-bit node IDs (susceptible to platform variance and collisions), and `send()` returned `true` immediately without waiting for GATT `onCharacteristicWrite` callback confirmation.
- **Remedy:**
  - Implemented `deterministicNodeId` and `deterministicMessageId` using SHA-256 byte extraction.
  - Added `writeMutex` and `pendingWriteDeferred: CompletableDeferred<Boolean>` in `MeshtasticBleTransport`.
  - Added `onCharacteristicWrite` callback handler in `BluetoothGattCallback`.
  - Implemented `sendPacketAsync` with 5-second timeout and truthful delivery result.
- **Verification:**
  - Added unit test suite `MeshtasticProtoSerializationTest.kt`.
  - `:core:mesh:testDebugUnitTest`: **BUILD SUCCESSFUL** (87 actionable tasks, all passed).
