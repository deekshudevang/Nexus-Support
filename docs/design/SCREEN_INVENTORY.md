## Navigation & Architecture Verification
- **Navigation Framework**: Type-safe Navigation Compose 2.8+ utilizing `@Serializable sealed interface Screen`.
- **Deep Links & Insets**: All screens enforce edge-to-edge window insets (`WindowInsets.safeDrawing`), dynamic system bar padding, and keyboard IME scrolling.
- **Accessibility**: High-contrast emergency color schemes (Material 3 Dark/Light), touch targets >= 48dp on all primary emergency controls, content descriptions for assistive screen readers (TalkBack). Physical TalkBack session registered as `IMPLEMENTED-PENDING-DEVICE`.
